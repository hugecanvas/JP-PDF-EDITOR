# JP-PDF EDITOR

설치 없이 실행하는 오프라인 PDF 편집기 (Windows). 텍스트·형광펜·도형을 **레이어 개체**로 얹어 편집하고,
'PDF로 저장'할 때만 PDF에 합칩니다.

## 내려받기 / 실행

`JP-PDF EDITOR.exe` 하나만 받아 실행하면 됩니다 (설치 불필요, 인터넷 불필요).

## 기능

- **텍스트**: 페이지를 클릭하고 그 자리에서 바로 입력 (Enter=줄바꿈, Ctrl+Enter·바깥 클릭=확정, Esc=취소)
  - 텍스트 상자는 글자 크기·내용에 자동으로 맞춰지고, 핸들을 끌면 글자 크기가 바뀜
  - 글꼴, 크기, 정렬, 굵기(보통 / 약간 굵게 / 굵게 / 아주 굵게), 글자색, 배경색
  - 더블클릭으로 그 자리에서 내용 수정
- **캡처 이미지 붙여넣기**: 화면을 캡처(Win+Shift+S, PrtSc)한 뒤 **Ctrl+V** → 현재 페이지에 이미지 레이어로 붙음
  - 탐색기에서 복사한 그림 파일(png·jpg·bmp 등)도 Ctrl+V로 붙여 넣기 가능
  - 이동·크기 조절(모서리 핸들은 가로세로 비율 유지)·순서·삭제, 작업 파일에 이미지 함께 저장
- **형광펜**: 글자 위를 드래그하면 줄 단위로 맞춰 칠함
- **도형 그리기**: 사각형, 둥근 사각형, 원/타원, 삼각형, 직선, 화살표, 양쪽 화살표 (선 색·채우기·두께·불투명도)
- **레이어**: 선택·이동·크기 조절, 앞/뒤 순서, 표시/숨김, 이름 변경, 복제·복사·붙여넣기, 모든 페이지에 복사
- **페이지**: 분할/추출, 병합, 삭제, 회전, 순서 변경, 빈 페이지·이미지·PDF 삽입
- **저장**: PDF로 저장(레이어 합침) 또는 작업 파일 `.pdfedit`(원본 PDF + 레이어 정보, 나중에 다시 수정 가능)
- 실행 취소(Ctrl+Z)

## 소스에서 실행 / 빌드

```
pip install "pymupdf==1.25.5" fonttools
python pdf_editor.py [파일.pdf 또는 파일.pdfedit]
```

exe 만들기: `build_exe.bat` 실행 → `dist\JP-PDF EDITOR.exe`

자체 점검: `"JP-PDF EDITOR.exe" --selftest 결과.txt`

- **v1.1** — 텍스트 상자 글자 크기 연동, 텍스트 굵기, 팝업 없이 페이지 위에서 바로 입력,
